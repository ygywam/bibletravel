# Bible Travel (주일학교 성경읽기 웹앱)

회정교회 주일학교 성경읽기 모험 웹 애플리케이션입니다.
Supabase (PostgreSQL BaaS) + Vercel Edge CDN을 기반으로 초고속 서빙됩니다.

## 주요 구성
- `index.html`: 메인 웹앱 진입점
- `styles.css`: 모바일 최적화 테마 스타일시트
- `app.js`: Supabase 실시간 연동 프론트엔드 엔진
- `cards/`: 성경 66권 수집형 BT 카드 이미지 (WebP 최적화)
- `maps/`: 8개 성경 유형 맵 배경 이미지 (WebP 최적화)
