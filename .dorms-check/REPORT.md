## 보안 최소 점검

- 결과: 확인된 위험 있음
- 확인 6건 · 미확인 2건 · 해당 없음 4건
- 점검 범위 밖의 내부 기능과 자료까지 안전하다는 뜻은 아닙니다.

### 확인된 위험

- SSL 인증서 유효: 공개 HTTPS 연결에서 인증서 오류를 확인했습니다.

### 보완하면 좋은 항목

- 헤더 설정 위치: 헤더 설정 파일에서 보안 헤더 설정을 못 찾음(라이브 관측을 우선 신뢰)
- 위험 코드 패턴(검토 후보): 검토가 필요한 위험 패턴 41건(문맥 확인 필요)
- 학교 자체점검표 운영 항목(참고): 코드에서 흔적을 찾지 못한 항목: 탈퇴·퇴직 계정 삭제 기능, 관리자 2단계 인증, 로그인 실패 제한(캡차·잠금), 오래 쓰지 않으면 자동 로그아웃, 접속·권한 변경 기록 보관, 요청 횟수 제한

### 확인하지 못한 항목

- 공개 화면: 공개 화면을 확인하지 못했습니다.
- 공개 화면: 공개 응답 검사를 완료하지 못했습니다.
